# Third-party notices

## OpenAlchemy

VectorCraft is a GitHub fork of [BloodyFish/OpenAlchemy](https://github.com/BloodyFish/OpenAlchemy), an open-source-intended Infinite Craft-inspired Python/NiceGUI experiment by BloodyFish. The fork preserves its full commit history and attribution.

At the time VectorCraft was forked (2026-08-23), OpenAlchemy did not include a license file or declare a license in GitHub metadata. Its historical code is therefore not relicensed by VectorCraft's MIT license. The current VectorCraft tree is a new browser-native implementation and contains none of the former Python/Gemini runtime files.
